## 1. 五分钟搞懂这个项目在解决什么问题

**肺癌的一种**(非小细胞肺癌，NSCLC)有一部分病人的肿瘤细胞里，一个叫**EGFR**
的蛋白质发生了突变，变成了持续"开机"状态，不断给细胞发"快速增殖"的信号——
这就是肿瘤。EGFR正常情况下是细胞表面的一个受体，外面有生长因子来"敲门"
它才会被激活；突变之后变成了不用敲门就一直激活，相当于一个开关坏了，
卡在"开"的位置。

**第一代/第二代靶向药**(吉非替尼、厄洛替尼)能堵住这个坏开关——它们是小分子，
钻进EGFR内部一个叫"ATP口袋"的结合位点，占着茅坑不让EGFR干活。但肿瘤细胞
会进化：在药物选择压力下，少数带有新突变(**T790M**)的细胞存活下来并增殖，
这个突变让口袋对药物的亲和力下降，第一代药失效了。

**第三代药奥希替尼(osimertinib)**针对T790M设计，而且用了一种更狠的招数：
不只是"占着"口袋，而是和口袋里一个叫**C797**的氨基酸残基**形成永久的化学键**
(共价结合)，相当于把自己焊死在口袋里，药效更持久更强。这个药现在是一线
标准治疗。

**但肿瘤细胞又进化了**：如果把C797这个残基本身突变掉(**C797S**)，奥希替尼
就没有东西可以焊接了，药又失效了。这就是本仓库要解决的核心问题——
**奥希替尼耐药之后怎么办**。

关键认知：这是一个**军备竞赛**，不是一次性解决的问题。每一代药解决上一代
耐药机制的同时，都给肿瘤细胞制造了新的选择压力，逼出新的耐药突变。这也是
为什么本仓库最后决定同时推进三条不同思路的路线(A/B/C)，而不是押注一条——
分散在不同的生物学逻辑上，比在同一个"口袋"里打补丁更不容易被同一招破解。

## 2. 细胞生物学速成：基因、蛋白质、突变

用编程语言类比最快：

| 生物学概念 | 编程类比 |
|---|---|
| DNA(基因组) | 源代码仓库 |
| 基因(gene) | 一个函数/模块的源码 |
| 转录+翻译(DNA->RNA->蛋白质) | 编译+链接，源码变成可执行的二进制 |
| 蛋白质(protein) | 跑起来的程序/可执行文件，真正"做事"的东西 |
| 突变(mutation) | 源码里的一个字符改动(可能是bug，也可能是性能优化，看改在哪) |
| 野生型(wild-type) | 代码库的默认/未修改版本 |
| 突变型(mutant) | 打了某个"补丁"之后的版本 |

**突变命名法**（你会在代码注释和yaml配置里反复看到，比如`L858R`/`C797S`）：
格式是"原氨基酸-位置编号-新氨基酸"。蛋白质是一串氨基酸(20种)像珠子一样
连起来折叠成的3D结构，每个位置用标准单字母缩写表示某种氨基酸：

- `L858R`：蛋白质第858个位置，原本是亮氨酸(Leucine, L)，突变成了精氨酸(Arginine, R)
- `C797S`：第797位，半胱氨酸(Cysteine, C)突变成了丝氨酸(Serine, S)——
  **关键细节**：半胱氨酸的侧链有一个硫原子(-SH)，这正是奥希替尼用来"焊接"
  的化学把手；丝氨酸没有这个硫原子，所以焊不上了。这就是C797S耐药的分子机制。
- `del19`：19号外显子缺失(deletion)，不是单点突变，是一段序列直接被删掉了——
  类比成代码里删掉了一整个函数体的一部分。
- `T790M`：第790位，苏氨酸(Threonine)突变成甲硫氨酸(Methionine)——这个位置
  正好在ATP口袋入口，突变后侧链变大("gatekeeper"突变)，像给门口塞了个大
  箱子，药物分子更难挤进去，同时ATP本身的亲和力还提高了(双重打击)。

**激酶(kinase)**：一类给其他蛋白质"贴标签"(磷酸化)的酶，相当于信号系统里的
"开关拨动器"。EGFR本身就是一个激酶，正常情况下被激活后，会把下游一串蛋白质
依次磷酸化激活，像多米诺骨牌一样传递"该增殖了"这个信号——这一串传递叫
**信号通路(signaling pathway)**，本仓库路线A针对的RAS-MAPK通路就是最经典
的一条。

**选择性(selectivity)**：药物只打中目标蛋白、不误伤长得很像的其他蛋白质。
类比成一个搜索/分类模型的**精确率(precision)**——模型不仅要能识别目标
(召回)，还不能把相似的东西也误判成目标(假阳性)。EGFR野生型、SHP1(路线A
的反靶点)都是和目标蛋白结构相似、但打中了会出问题的"易混淆类别"。

## 3. 药物是怎么起作用的：四种机制

### 3.1 小分子抑制剂——占着茅坑不让干活

绝大多数靶向药(包括路线C)都是这个套路：小分子钻进蛋白质的一个功能性口袋
(通常是激酶的ATP结合口袋)，把原本该结合的东西(ATP)顶替掉，让蛋白质没法
正常工作。

- **可逆(reversible)**：结合是动态平衡，药物分子会结合-解离-再结合，像
  磁铁吸在冰箱上，用力能拿下来。
- **共价(covalent)**：药物分子上有一个反应活性基团(**弹头/warhead**，比如
  丙烯酰胺)，会和口袋里某个氨基酸(通常是半胱氨酸的硫)发生化学反应，
  **形成永久的共价键**，像用胶水粘上去，正常条件下拿不下来。优点是药效更持久
  (哪怕血药浓度降下来，已经焊上的分子还在起效)、选择性可能更好；缺点是
  如果弹头反应性太高，可能误打到别的蛋白质上(脱靶毒性)，而且耐药的一种
  方式就是把那个被焊接的氨基酸本身突变掉(C797S正是如此)。
- **变构(allosteric)**：不占据主口袋，而是结合在蛋白质表面另一个位置，
  通过"掰弯"蛋白质的3D形状，间接让主功能区失活。本仓库路线A(SHP2/SOS1)
  用的就是这个机制——类比成不是堵住USB口，而是按一个远程的电源总开关。

### 3.2 ADC(抗体药物偶联物)——用抗体当导弹制导系统

一个抗体(能精确识别并结合特定细胞表面标志物)拴着一个"弹头"(通常是化疗药，
毒性很强但不能直接全身注射)，中间用一段化学"linker"连起来。抗体负责"制导"，
专门找到表达目标蛋白的细胞再释放弹头，理论上能减少对正常细胞的伤害。本仓库
提到的HER3-DXd就是这类药——它最终因为总生存期(OS)数据不够好而撤回申请，
这是立项分析里最重要的一条教训(见[doc/competitive-landscape.md](competitive-landscape.md))。

### 3.4 降解剂(PROTAC/molecular glue)——不抑制，直接销毁

这是路线B用的机制，也是四种里最反直觉的一个，值得展开讲。

细胞内有一套"垃圾处理系统"叫**泛素-蛋白酶体系统(ubiquitin-proteasome
system)**：细胞要降解一个不再需要的蛋白质时，会先给它贴上一串叫**泛素
(ubiquitin)**的"待销毁"标签(这个贴标签的过程需要E1→E2→E3三类酶接力完成，
**E3连接酶**负责"认出"具体是哪个蛋白质该贴标签，相当于垃圾分类系统里决定
"这个东西该不该扔"的那个判断模块)，贴完标签的蛋白质会被一个叫**蛋白酶体
(proteasome)**的桶状结构"绞碎"分解掉。

**降解剂的核心思路**：设计一个**双功能分子**，一端能结合目标蛋白(比如突变
EGFR)，另一端能结合某个E3连接酶(常用CRBN或VHL)，中间用一段**linker**连起来。
这个分子相当于**强行把目标蛋白和E3连接酶拉到一起**，骗过细胞的垃圾分类系统，
让它误以为目标蛋白也该贴泛素标签——于是目标蛋白被当成垃圾降解掉了。

类比成软件里的**依赖注入/强制绑定**：正常情况下E3连接酶只认识它天然的
底物，降解剂相当于用一个"适配器"把一个本来不认识的对象硬塞给它，让它
接受并处理。

这个机制有几个重要性质，都体现在`core/ternary_complex.py`和
`doc/routes/route-b-degrader.md`里：

- **催化式作用**：一个降解剂分子用完一次(促成一次降解)可以解离出来接着用，
  不需要像抑制剂那样持续占据口袋跟体内ATP"拼浓度"，理论上药效浓度可以更低。
- **三元复合物(ternary complex)**：目标蛋白-降解剂-E3连接酶三者同时结合
  形成的复合物，这是决定降解效率的关键，光看"降解剂和目标蛋白结合得好不好"
  (二元结合)是不够的——两边结合得都好，不代表三个凑在一起的时候构象合适、
  不会互相"打架"。
- **Hook effect(钩状效应)**：一个反直觉的现象——药物浓度太高的时候，降解剂
  分子会各自单独把目标蛋白和E3连接酶"占满"(每个蛋白质分子身上都挂着一个
  降解剂，但两种蛋白质各自为政，没有被同一个降解剂分子同时拉到一起)，三元
  复合物反而变少了，药效在高浓度下不升反降，剂量-响应曲线呈现"先升后降"的
  钟形，而不是常见的"浓度越高效果越好"的单调曲线。这就是为什么降解剂的TPP
  里需要专门评估"安全剂量窗"(见`core/ternary_complex.py::evaluate_hook_effect_risk()`)。

## 4. 新药研发管线全景：从靶点到病人

一个新药从想法到上市大致要经过：

```
靶点发现 -> 苗头化合物(hit) -> 先导化合物优化(lead optimization)
  -> 临床前研究 -> I期临床(安全性) -> II期临床(初步疗效)
  -> III期临床(大规模对照验证) -> 监管审批(FDA的NDA/BLA) -> 上市
```

本仓库(`core/`+`routes/`)对应的是**先导化合物优化**这一阶段——这是一个
不断循环的过程，叫**DMTA循环**(Design设计-Make合成-Test测试-Analyze分析)，
对应环节9(`core/feedback.py`)。为什么要循环：药化不可能一次设计出完美分子，
而是设计一批、测一批、根据结果调整下一批的设计方向，像敏捷开发里的迭代
sprint——每一轮都是一次"发布-收集反馈-改进"。

**为什么要用计算化学**：在湿实验室里合成一个分子、测它的活性，需要几周时间
和几千美元；用计算方法预测同样的问题，便宜的方法几秒钟几乎免费，贵的方法
(FEP)也就是几个GPU小时。所以整个管线被设计成一个**漏斗**：先用最便宜的方法
筛掉明显不行的候选(可能从几十万个分子里筛到几千个)，然后逐级用更贵更准的
方法收窄范围，最后只有最有希望的几十个分子才真正拿去湿实验室合成和测试。

这和软件测试里的**测试金字塔**是同一个思路：单元测试(快、便宜、量大)在底层
跑很多，端到端测试(慢、贵、准确)在顶层只跑少数关键场景。详见
[doc/04-funnel-docking.md](04-funnel-docking.md)的L0-L4分级。

**多目标决策(环节8)**：一个好分子不是单一指标好就行，要同时满足活性、
选择性、安全性、可合成性等一堆互相牵制的要求——这是经典的**多目标优化**
问题，本仓库用**Pareto前沿**(找不存在另一个方案在所有维度都不比它差的解)
和**几何平均打分**(而不是加权求和，避免一项极端好掩盖另一项致命差)来处理，
详见[doc/08-decision.md](08-decision.md)。

## 5. 计算化学方法速查：这些其实都是搜索/优化算法

| 方法 | 在算什么 | 编程类比 |
|---|---|---|
| **SMILES** | 用一串文本字符串编码分子的2D结构 | 分子的"序列化格式"，相当于分子界的JSON/Protobuf |
| **分子指纹(fingerprint)** | 把分子编码成一个定长的0/1向量，记录有哪些子结构 | 类似NLP里的词袋模型/embedding，用来快速算相似度 |
| **药效团匹配(pharmacophore)** | 检查分子是不是在正确的空间位置上有正确类型的官能团(这里要有氢键供体、那里要有疏水基团) | 类似用正则表达式/规则引擎做超快速的粗筛，不算精确能量，只看"形状和特征对不对" |
| **分子对接(docking)** | 搜索一个小分子在蛋白质口袋里的最佳3D姿态(位置+朝向+构象)，并打一个近似的结合能分数 | 组合优化问题(搜索空间巨大，用启发式算法如遗传算法找局部最优解)，输出结果更像是"大致排序"，不是"精确数值"——这也是为什么环节4一直强调"Vina打分只能用来排除，不能用来精排" |
| **分子动力学(MD)** | 用牛顿力学模拟体系里每个原子随时间的真实运动轨迹 | 一个物理引擎的时间步进仿真(类似游戏引擎的物理模拟循环)，用来检查一个对接姿势是不是只是"看起来合理"还是真的能稳定存在一段时间 |
| **MM-GBSA** | 从MD轨迹的多帧快照里，用一个近似的能量公式估算结合自由能 | 比FEP便宜的近似计算，牺牲一些精度换取速度——类似用启发式剪枝代替穷举搜索 |
| **自由能微扰(FEP)** | 精确计算两个相似分子之间结合自由能的**差值**(不是绝对值)，通过模拟一个"炼金术"式的虚拟路径，让分子A逐渐在计算机里"变成"分子B，统计这个过程的能量变化 | 本管线里最贵但最准的方法，几个GPU小时跑一对分子，相当于CI流水线里最慢但最权威的端到端测试，只用在决赛圈的候选上 |
| **结构警示(structural alerts)** | 用SMARTS子结构匹配规则，识别已知有毒性风险的化学基团(比如硝基芳烃、未掩蔽苯胺) | 纯规则引擎/静态代码分析——类似linter检查代码里的已知反模式，不需要运行代码就能发现问题 |

**一个重要的认知**：这些方法的精度是分层的，误差量级从L0到L4依次下降
(大致2.5→2.0→1.3→0.75 kcal/mol)，但计算成本也依次上升几个数量级。
**早期方法只能用来"排除"，不能用来"排名"**——这是整个管线设计里反复强调
的一条红线，详见[doc/04-funnel-docking.md](04-funnel-docking.md)。

## 6. 关键指标缩写词典

### 6.1 效力/亲和力指标(分子有多"强")

| 缩写 | 全称 | 含义 |
|---|---|---|
| IC50 | half maximal Inhibitory Concentration | 让目标功能被抑制50%所需的药物浓度，越低越强。**注意**：这个数值会随实验条件(比如底物/ATP浓度)变化，不同实验室的IC50不能直接横向比较 |
| Ki | inhibition constant | 真实的热力学抑制常数，和实验条件无关(可以从IC50用Cheng-Prusoff公式换算)，比IC50更"纯粹" |
| Kd | dissociation constant | 纯粹的结合平衡解离常数，衡量"结合"这件事本身，不一定代表"抑制了功能"(结合了不代表一定抑制) |
| EC50 | half maximal Effective Concentration | 产生50%最大效应所需的浓度，常用于细胞/功能性检测 |
| DC50 | half maximal Degradation Concentration | **降解剂专属**：降解掉50%目标蛋白所需的浓度 |
| Dmax | maximal Degradation | **降解剂专属**：浓度饱和时能达到的最大降解百分比——哪怕DC50很低，如果Dmax只有50%，还是有一半目标蛋白没被清除 |
| kinact/KI | — | **共价抑制剂专属**：共价结合分两步(先可逆结合KI，再形成共价键kinact)，这个比值才是共价药的正确效力指标，**IC50对共价药没有意义**(因为共价键不可逆，孵育时间越长表观IC50越低，这个数字不稳定) |

### 6.2 ADMET(药代动力学与安全性)

ADMET = **A**bsorption吸收 + **D**istribution分布 + **M**etabolism代谢 +
**E**xcretion排泄 + **T**oxicity毒性——合起来就是"药进了身体之后发生了什么、
会不会有毒"。

| 缩写 | 含义 | 为什么重要 |
|---|---|---|
| MW | 分子量 | 太大通常口服吸收差、难穿透血脑屏障 |
| cLogP | 计算的辛醇/水分配系数 | 衡量脂溶性，太高容易脱靶/毒性增加，太低吸收差 |
| cLogD(7.4) | 生理pH下的分配系数 | 比cLogP更贴近体内真实情况(考虑了电离态) |
| TPSA | 拓扑极性表面积 | 和细胞膜穿透能力负相关，CNS药物通常要求TPSA较低 |
| HBD/HBA | 氢键供体/受体数量 | 影响膜穿透和溶解度 |
| Rule of Five(Ro5) | Lipinski五规则 | 口服药物"经验友好区间"的粗略判据(MW<500, cLogP<5等)；**PROTAC/降解剂天然违反这个规则**(分子量常700+)，这是路线B要面对的真实挑战 |
| hERG | 一种心脏钾离子通道 | 被误打中会导致心律失常风险(QT间期延长)，几乎每个项目都要专门筛这个，和"带正电的碱性胺+高亲脂性"这个组合强相关 |
| Kp,uu | 游离药物脑血分配比 | CNS渗透的金标准指标(只算"自由"的、真正有药理活性的那部分药物浓度，不算被蛋白结合"困住"的部分) |
| CNS MPO | 多参数复合打分 | 把MW/cLogP/cLogD/TPSA/HBD/pKa揉成一个0-6分的综合分，快速评估"这个分子适不适合做中枢神经系统药物" |

### 6.3 临床试验终点

| 缩写 | 含义 | 备注 |
|---|---|---|
| ORR | 客观缓解率(Overall Response Rate) | 肿瘤明显缩小的病人比例，相对容易达到 |
| PFS | 无进展生存期(Progression-Free Survival) | 病情不恶化的持续时间，比ORR更有临床意义但还不是终极指标 |
| OS | 总生存期(Overall Survival) | 病人实际活了多久，**最难打、最有说服力**的终点——本仓库反复强调的HER3-DXd案例就是ORR/PFS都不错但OS没打出显著差异，最终导致申请被撤回 |
| HR | 风险比(Hazard Ratio) | 两组之间"事件发生风险"的相对比值，HR<1表示治疗组更好，比如HR=0.56表示疾病进展/死亡风险降低了44% |
| IND | 新药临床试验申请 | 开始人体试验前必须向监管机构提交 |
| NDA/BLA | 新药上市申请(小分子/生物制品) | 完成临床试验后申请正式上市 |
| Fast Track | FDA快速通道认定 | 给未满足医疗需求的项目加速审评流程，不代表药一定有效，只是流程优先 |

### 6.4 药物化学日常术语

- **SAR(构效关系，Structure-Activity Relationship)**：药物化学最核心的工作
  方法——系统性地改变分子的某一部分，观察活性/性质怎么变化，积累对"什么
  结构特征对应什么效果"的理解。本仓库的`core/enumerate.py`按口袋区域枚举
  R基团组合，本质就是在批量生成SAR探索所需的分子。
- **先导化合物(lead compound)**：活性和基本性质都不错、值得投入资源深入
  优化的起点分子。
- **骨架(scaffold)**：分子的核心不变部分，优化时固定骨架、只改变周边的
  可变基团(R基团)——这是`config/rgroup_libraries/scaffolds.yaml`里
  `core_smiles`+`attachment_points`这套数据结构的生物学意义。

## 7. 三条路线各自需要的额外背景

### 路线A：SHP2/SOS1——RAS-MAPK通路的"收敛阀门"

很多不同的上游信号(EGFR、MET、HER2等多种受体激酶)最终都会往下游同一条
通路汇聚：**RAS-MAPK通路**。简化版流程：受体激酶激活 → 招募衔接蛋白 →
**SOS1**(一种"交换因子"，把RAS从关闭态GDP结合切换成开启态GTP结合) → RAS
开启 → RAF → MEK → ERK → 进细胞核激活增殖基因。

**SHP2(基因名PTPN11)**是一个磷酸酶(本职工作是去掉磷酸基团，通常磷酸酶被
认为是"关闭信号"的角色)，但在这条通路里它是个例外——SHP2对RAS信号的
**正常激活是必需的**(它负责清除掉一些抑制性的磷酸化位点，帮助SOS1顺利
招募上岗)。所以抑制SHP2或SOS1都能把这个通路从源头掐断，不管上游是EGFR、
MET还是别的什么受体在驱动。这就是路线A"收敛点"策略的生物学基础——
一个药理论上能同时管住多种不同上游耐药机制共同导致的下游问题。

SHP2的抑制剂是**变构抑制剂**(见第3.1节)，结合在一个由三个蛋白结构域
(N-SH2/C-SH2/PTP)组成的"隧道(tunnel)"位点，锁住蛋白质的自抑制构象。

### 路线B：泛素-蛋白酶体系统——见第3.4节

第3.4节已经详细讲了降解剂的机制。路线B额外要懂的两个概念：

- **CRBN(cereblon)**：最常用的"E3连接酶招募配体"靶点之一。沙利度胺
  (thalidomide，历史上臭名昭著的"反应停"药物)类似物——来那度胺、
  泊马度胺——都是通过结合CRBN起作用的，现在也是PROTAC设计里最常用的
  "E3配体"模块(本仓库`e3_ligands.yaml`用的就是这两个)。
- **协同效应(cooperativity, α)**：三元复合物形成时，目标蛋白和E3连接酶
  之间如果存在正向相互作用(比如形成了额外的蛋白-蛋白接触面)，会让三元
  复合物比"单纯靠两个独立的二元结合拼起来"更稳定——这是真正优秀降解剂
  和平庸降解剂的分水岭，但目前的计算方法还很难精确预测，这正是
  `core/ternary_complex.py`里诚实标注为"未实现"的部分。

### 路线C：共价化学——弹头反应性和攻击角几何

共价抑制剂的弹头(通常是丙烯酰胺一类"迈克尔受体")要通过一种叫**迈克尔加成
反应**的化学反应，和半胱氨酸的硫原子形成共价键。这个反应对**攻击角度**
很敏感——弹头的碳原子要以一个接近105°的角度("Bürgi-Dunitz角"，这是根据
大量晶体结构统计出的化学反应最优轨迹角)去靠近硫原子，才容易反应。这就是
`core/covalent.py::evaluate_attack_geometry()`在检查的东西——纯几何判断，
不需要做真正的反应能垒计算。

弹头的反应性也要适中：太弱了结合不上，太强了会在血液里乱打一通(非特异性
共价修饰，可能导致免疫原性/特异质肝毒性)，这就是为什么`pipeline.yaml`里
会设定一个GSH半衰期的目标区间(GSH是细胞内最主要的亲核清除剂，用它来模拟
弹头在体内的本征反应性)。
