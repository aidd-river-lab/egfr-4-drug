# 三条路线各自离工业级还差哪些、接下来具体怎么做

[doc/11](11-industrial-gap-and-roadmap.md)讲的是三条路线**共同**的差距
(实验闭环、团队、合规这些结构性的)，这篇补上**每条路线各自单独的**缺口——
数字全部来自数据库真实查询(不是回忆)，查询方式见本文末尾，随时可以自己
重新跑一遍核对。

## 先看一张总览表(真实查库结果)

## 路线A(SHP2/SOS1)：三条里结构数据最扎实，但一步验证没做

**已经做对的**：5EHR(SHP099/SHP2)、6SCM(BI-3406/SOS1)都是真实下载+清洗的
共晶结构，16个候选分子真实对接出有区分度的分数，决策批次也真实跑完选出
10个。这是三条路线里"结构生物学输入"最扎实的一条(配体HETATM确认存在，
不需要像路线C那样先走计算突变)。

**真正的缺口**：

1. **从没有为SHP2/SOS1单独做过retrospective验证**——这次做的DUD-E验证
   只覆盖了EGFR这一个靶点/口袋类型，变构位点(SHP2的"隧道"位点)和ATP
   竞争性口袋的几何特性完全不同，EGFR上验证出的AUC=0.69**不能直接套用**
   到SHP2/SOS1上。要知道Vina在这类变构口袋上到底准不准，必须单独查
   SHP2/SOS1的已知活性数据(DUD-E有没有收录SHP2需要查，备选ChEMBL/
   BindingDB直接查真实IC50数据)再跑一次同样的AUC/EF计算。
2. **环节5(选择性引擎)完全没跑**——这恰好是设计文档原话"整条管线最该
   投入算力的地方"，而路线A因为变构位点结构清楚、共晶多，被认为是三条
   路线里**FEP最友好**的一个(`competitive-landscape.md`里的原话)，
   意味着如果要在三条路线里选一条先投入真实FEP算力，路线A性价比最高，
   但目前这个优势完全没兑现成实际跑过的结果。
3. 骨架仍是`illustrative_only`，没有专家review；FTO仍是placeholder。

## 路线B(降解剂)：三条里客观上最落后，不是态度问题，是真实的方法学卡点

**已经做对的**：4TZ4(CRBN+来那度胺)真实共晶结构、E3配体真实Ki查证属实
(来那度胺≈3100nM)、三元复合物几何筛选真实跑过一整套(warhead对接+Kabsch
刚体变换追踪+500次随机采样)，还诚实产出了一个有统计量支撑的负向发现
(0/500次找到几何兼容姿态)。

**真正的缺口，比另外两条路线更本质**：

1. **10个候选分子从来没有被对接过——已经补上，过程中发现一个值得记录的
   方法学陷阱**。第一次尝试直接把10个完整的双功能分子(warhead-linker-
   E3配体，MW 700-900)整个扔给Vina对接，技术上全部"成功"
   (-7.96~-9.73 kcal/mol，看起来分数还不错)——但检查对接出来的姿态
   发现这些分数**不能信**：真实姿态的空间延展只有约10-16Å，说明Vina
   把整个又长又大的分子硬折成一个紧凑小球塞进了给小分子设计的对接盒子，
   不是真实的PROTAC结合模式(warhead在口袋里、linker和E3配体伸到溶剂里
   够向另一个蛋白)。这组数字已经从数据库删掉，没有留着当真实结果用。

   正确做法：10个候选共享同一个warhead(`demo_warhead_from_route_c_scaffold`)，
   单独把这个warhead片段(接口端补氢封闭)拿去对接，真实分数**-8.19
   kcal/mol**——这个量级和路线A/C真实候选的分数相当，说明warhead本身
   结合EGFR口袋没问题。已经用这个分数覆盖性地写入`funnel_scores`(10个
   候选都是同一个值，因为它们的target-engagement模块是同一个片段)。
   **诚实的边界**：这仍然只是L1对接分数(kcal/mol)，不是真实的
   `warhead_kd_nm`(纳摩尔级Kd)——把-8.19 kcal/mol硬换算成一个Kd数字
   拿去跑后面的hook effect/决策算法，会赋予这个粗糙估计不该有的精确度
   (L1误差量级±2.5 kcal/mol，换算成Kd的不确定度有七十多倍)，本仓库没有
   这么做，第2点的决策缺口依然存在。
2. **没有任何决策批次**——`decision_rounds`表里压根没有路线B的记录，
   原因是`warhead_kd_nm`这个核心输入始终缺失(需要环节4对接/FEP产出，
   而环节4本身都还没跑)，而本仓库的原则是"没有真实Kd就不编一个假的去
   跑决策算法"，所以宁可留空也不跑一个基于假数据的决策。
3. **三元复合物的采样策略已经被证明走不通**：均匀随机刚体采样500次，
   0次找到兼容姿态，不是运气不好，是方法学本身的限制(两个蛋白表面各自
   很窄的连接点，靠随机转向撞上的概率天然很低)。这是一个需要**做决定**
   的真实分叉点，不是继续调参能解决的：
   - 要么投入做约束采样(朝着已知exit vector大致方向偏置采样，而不是
     均匀随机)，工程量不小；
   - 要么接受"轻量版走不通"这个结论，正式把路线B的三元复合物预测标记
     为"需要PatchDock或等价工具，当前搁置"，先把前面两个缺口(对接+决策)
     补上，不被三元复合物这一个最难的子问题卡住整条路线的进度。
4. CNS MPO公式按传统小分子校准，套在beyond-Ro5的双功能分子上系统性
   失准(已知局限，`run_bifunctional_round.py`的输出已经标注过，没有修)。

## 路线C(四代TKI)：三条里最成熟，但也暴露了最多"看起来完整、实际没验证"的缝

**已经做对的**：324个候选分子完整走过标准化→枚举→ADMET→决策全流程，
24个真实对接分数(交叉验证两个基因型，Spearman一致)，PyRosetta真实计算
出了主要基因型(L858R/C797S)原本没有晶体结构的计算模型，刚做完的DUD-E
retrospective验证(AUC=0.69)。这是三条路线里唯一有完整端到端参照实现的。

**真正的缺口**：

1. **retrospective验证的覆盖范围要讲清楚边界**：这次验证的是"Vina对
   EGFR这个蛋白家族/口袋类型有没有区分力"，用的542个真实活性分子基本是
   针对野生型/经典突变的历史数据，**几乎不包含专门针对C797S三重突变体系
   测过的化合物**(这是数据层面的硬约束——文献本身稀疏，不是没去找)。
   AUC=0.69这个数字不能直接说成"本仓库对C797S的预测有69%准确"，这是
   常见的过度引用错误，要主动避免。
2. **纠正上一版这里的一个不准确说法——已经真实补上，结果如下**。上一版
   写的是"路线C核心机制是共价结合，但从没在真实候选上跑过几何判据"，
   这句话本身不准确，查证后更新：**真实的324个候选分子用的
   `demo_aminopyrimidine_biphenyl`骨架，`chemistry_route.primary`配置的
   是`reversible_orthosteric`(可逆正构，不是共价)，`covalent_warhead_enabled:
   false`——这批候选分子根本不含任何共价弹头，没有东西可以测几何**。
   共价(`covalent_new_site`)只是配置里的backup选项，从未真正落地到任何
   一个候选分子的结构上。真正含共价弹头的只有奥希替尼这一个外部参照分子，
   而本仓库现有的全部C797S受体结构(6LUD及其衍生的PyRosetta模型)里797位
   都已经突变成Ser——这正是C797S耐药机制本身，意味着这些结构里根本没有
   真实的Cys-SG可供测量。

   **于是真实做的是**：新增`core/covalent.py::extract_michael_acceptor_geometry()`
   (从一个真实对接姿态里，纯几何识别丙烯酰胺端位烯烃碳+量出到指定亲核
   原子的距离/角度，不依赖PDBQT不可靠的CONECT信息，4个单测验证了识别
   逻辑本身)，用真实PDB **4ZAU**(标题"AZD9291 COMPLEX WITH WILD TYPE
   EGFR"，SEQADV确认790/797位都未突变，Cys797完整保留)，把奥希替尼当
   完整小分子非共价对接进去(真实Vina打分-7.134 kcal/mol)，量出的真实
   几何：**弹头碳到Cys797-SG距离6.05Å，攻击角155.1°**(偏离105°目标
   50.1°，超出±15°容忍区间，`evaluate_attack_geometry()`判定
   `geometry_ok=False`)。

   **这个结果本身是一个有价值的诚实负向发现，不是实现bug**：6.05Å已经
   远超共价反应可行的距离量级(真实反应前的encounter complex通常要在
   4Å以内)，说明普通非共价Vina对接**没有能力**把奥希替尼的弹头摆到真实
   会发生共价反应的那个姿态上——这完全符合预期，因为Vina的打分函数/
   搜索算法从头到尾都不知道"这个位置应该形成共价键"这件事，只会按
   非共价的形状/静电互补性去找一个能量最低的姿态，这个姿态可能和真实
   反应前体姿态完全不是一回事。这是一个真实、量化出来的证据，支撑了
   本仓库从一开始就强调的那句话："真实共价对接需要CovDock/Rosetta，
   普通Vina对接做不到"——现在不只是定性地这么说，有具体数字了。
   完整脚本见`scripts/run_covalent_geometry_check.py`。
3. `fto_status`在数据库里全部是NULL，不是"placeholder_not_real"这个
   占位值，说明`check_fto()`从未真正对任何一个候选分子持久化执行过。
4. 赛道拥挤的外部现实没变：3个真实项目同时在跑(silevertinib/
   tigozertinib/BBT-176)，其中silevertinib已经公开披露了本该是护城河的
   CNS渗透真实数据。

## 2026-10补充：路线A的SHP2专属retrospective验证——真实跑完了，结果比EGFR弱

查证后发现DUD-E的102个靶点里**没有SHP2(PTPN11)也没有SOS1**(完整列表
已核对，不是猜的)，这类较新的变构靶点不在2012年发表的DUD-E原始收录范围
内。ChEMBL的API一开始返回500错误(两条独立路径验证过是服务端故障)，
**隔了一天后再查，服务恢复了**，于是改用真实ChEMBL数据跑了一遍。

**方法**：查CHEMBL3864(人源PTPN11/SHP2)真实IC50/Ki记录，过滤掉27条标记
有质量问题的，按分子去重取中位数，active(IC50≤1μM)和inactive(≥10μM)
分别筛出1420和279个——**真实分布和DUD-E正好相反**(DUD-E是少活性多诱饵，
这里是多活性少无效)，这是药化文献本身的发表偏向，不是抽样偏差。为控制
对接总耗时，active随机抽样(种子42)到400个，inactive全部保留(更稀缺的
一类)，总共679个真实化合物，对接进真实5EHR受体(SHP099变构tunnel位点，
box中心从真实配体坐标量出来的)。

**真实结果**：674个成功(5个配体准备失败，占比0.7%，不影响结论)。

| 指标 | 数值 | 对比EGFR那次(DUD-E) |
|---|---|---|
| AUC | **0.575** | 0.69 |
| n_active / n_inactive | 395 / 279 | 542 / 2000 |
| active平均打分 | -8.42 kcal/mol | -9.70 kcal/mol |
| inactive平均打分 | -8.41 kcal/mol | -8.89 kcal/mol |
| EF@top5% | 1.30倍 | 2.99倍 |
| EF@top20% | 1.15倍 | 1.98倍 |

**AUC=0.575，比EGFR那次(0.69)明显更弱**，几乎只比随机好一点
(`core/validation.py`判定"弱区分能力，比随机好但不多")。active和inactive
的平均打分几乎一样(-8.42 vs -8.41)——这次对接**基本没能把真实有效和真实
无效的化合物分开**。

**为什么会更弱，有两个很可能的原因，脚本docstring提前就标注过这个风险**：

1. **这里的"无效"分子是真实测过的弱效化合物，大概率是同一个优化系列里
   活性分子的结构类似物**，不是DUD-E那种故意选得"性质像但结构不像"的
   诱饵——结构越像，对接分数也越难区分开，这是一个比DUD-E**更难**的任务，
   AUC更低不代表方法更差，可能只是题更难。
2. **更可能的解释：绑定位点不匹配**。ChEMBL里"SHP2抑制剂"这个大类历史上
   混杂两种完全不同机制的化合物——5EHR代表的变构tunnel位点(SHP099那类)，
   和另一类直接堵催化半胱氨酸的活性位点抑制剂。本次没有逐个化合物查文献
   确认绑定位点，如果真实active里混进了不少活性位点抑制剂，它们被强行
   对接到tunnel位点，打分自然和真正无效的分子差不多——不是方法没有区分
   力，是"问错了口袋"。

**这个结果诚实地说明什么**：路线A目前16个真实候选分子的对接分数，**不能
假定和EGFR那次一样可信**——SHP2这个靶点上，用5EHR这个受体做的Vina对接，
区分能力明显更弱，排序结果要比路线C更谨慎地只当粗筛用，不要当排名用。
如果要搞清楚是"任务更难"还是"问错了口袋"，下一步需要逐个化合物查文献
标注真实绑定位点，重新分组后再验证一次——这个工作量不小，值得先问你
要不要投入，而不是直接去做。

原始数据：`validation/chembl_shp2/results/docking_scores.csv`；脚本：
`scripts/run_chembl_shp2_validation.py`。

## 接下来具体怎么做：按性价比排序，不是按路线编号排序

1. **路线C的共价几何判据——已完成**，结果见上文"2026-10补充"部分：
   真实候选分子其实不含弹头(配置是reversible_orthosteric)，所以改用
   奥希替尼+真实PDB 4ZAU测了一次正例，结果是`geometry_ok=False`(非共价
   对接给不出真实反应前的姿态，这是量化验证了"Vina做不了共价对接"这条
   早就知道的限制，不是新bug)。新增的`extract_michael_acceptor_geometry()`
   是可复用的真实函数，不是一次性脚本。
2. **路线B的分叉点需要你做一个决定，不是我能单方面决定的**：10个候选
   先对接起来(这部分不需要新讨论，直接复用`core/docking.py`的既有流程，
   工作量和路线A/C的对接是一样的)；但三元复合物要不要投入约束采样，
   还是正式搁置——这是一个值得明确拍板的分叉，直接影响接下来要不要在
   这个方向上继续花时间。
3. **路线A的SHP2专属retrospective验证——已完成**，结果见上文"2026-10
   补充"部分：AUC=0.575，明显比EGFR那次(0.69)弱，active/inactive平均
   打分几乎一样——路线A现有16个候选的对接排序要比路线C更谨慎地只当粗筛
   用。真正弱在"任务更难"还是"问错了口袋"(ChEMBL的SHP2数据可能混了
   活性位点和变构位点两类不同机制的抑制剂)还没查清楚，需要逐个化合物
   核对文献绑定位点，工作量不小，是否要投入需要你决定。
4. **三条路线共同的、需要找人/花钱才能动的部分**(不是代码能解决的，
   和[doc/11](11-industrial-gap-and-roadmap.md)第5节一致，这里不重复)：
   找领域专家review骨架、真实FTO检索、有实验伙伴把预测和真实合成测试的
   数据对一次账。

**你现在要做的决定**：2(路线B三元复合物要不要投入约束采样)是一个需要你
明确选择的分叉点；3(要不要花时间逐个化合物查文献确认SHP2绑定位点分类)
是另一个需要你拍板的分叉；4是需要你去找外部资源(人/钱)才能推进的，不是
我能在这个环境里继续计算出来的。
